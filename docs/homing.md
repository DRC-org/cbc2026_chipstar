# コート別の自動ホーミング

自動ホーミングを使わず、r・zを手でリミットに当て、θの正面を記録することもできる。
「原点を設定する」で「手動で原点を設定する」（□）を選ぶ。手順は[手動の原点設定](host_operation.md#セッティングから競技開始)を参照。

「1 準備・操縦」で赤コートか青コートを選ぶ。
「最初に戻る」とコート選択ではθの保持を解除する。既に保持中のzだけを保持し、無効だったzは有効化しない。
機体を真正面に向け、z下降・上昇、θ旋回、r前進・後退の全経路に干渉がないことを確認して
「自動ホーミングを開始する」を押す。開始時の向きをθ=0°として記録する。
θ軸の単位はdeg、`origin_position`は0とする。

1. θの正面位置を原点として記録する。EE回転が有効なら、その時点のSTS実測位置から
   EEのフィールド角も保存する。その後、r・zの古い原点を無効にする。
2. 全出力を停止してr・zを再初期化し、停止応答を待つ。
3. zだけを有効化し、下端リミットまで低速で下降する。
4. 停止を確認し、zの下端を原点として設定する。
5. zを設定量だけ加減速しながら上昇させる。実測が目標の±1mm以内になったら、θを有効化する。
6. zを保持しながら、設定した「ホーミング旋回角」まで旋回する。青は正方向、赤は負方向。
   省略時は90°（青θ=+90°、赤θ=-90°）。
   θの最高速度にホーミング速度率を掛けた速度を上限とし、加減速しながら移動する。
7. θが目標の±1°以内に到達したら、その位置を保持してrを有効化する。
8. rを前端リミットまで伸ばし、rの出力を解除する。
9. リミットと出力解除の応答を確認し、その位置をrの原点に設定する。
10. rを再度有効化し、設定量だけ加減速しながら後退する。原点はリミット位置を基準に維持する。
11. 実測が後退目標の±1mm以内でリミットも解除されたら、rの出力を解除して終了する。
    θ・zは保持を続ける。EE回転が設定されている場合は、正面合わせ時に記録したEEの向きを復元して保持する。
    通常操縦は自動再開しない。

ホーミング後の最初のスタートは、r・zを保持しながらθを正面0°へ加減速して戻す。
正面復帰中はアームの手動操作を待ち、完了後はそのまま通常操縦へ移る。EEのθ追従は復帰中も継続する。
PSで復帰を中断するとその位置を保持し、次のスタートで正面復帰を再実行しない。
通常の停止・再開は、その位置を保持したまま操縦を再開する。
取得シーケンスを直接開始した場合は、その工程の移動先を使う。

ホーミング中のEE回転出力は停止したままにする。ホーミング完了後、「開始姿勢に合わせる」の段階から、
正面合わせ時に保存したフィールド角を現在のθ位置で再計算して復元し、θへ追従して向きを保持する。
EE回転の保持は最初の操縦開始・正面復帰へ引き継ぐ。停止・最初からやり直し・緊停・通信異常では
EEの保持を解除し、自動で有効化し直さない。通常の再開時は最新の実測姿勢を採用する。

GUIとDualSenseは同じ手順を使用する。停止中に入力を中立にし、機体が真正面を向いていることと
移動経路を確認してCreateを1秒長押しすると開始する。PSで中断でき、パッド切断でも中断する。
完了・中断後の再実行にはCreateを一度離す必要がある。

開始前にコートと軸設定・接点・フィードバックを確認する。
コート未選択、θ旋回先が可動域外、θ原点座標が0以外の場合は駆動指令を送らない。
θ旋回角は「2 調整 → アーム → θ」の「ホーミング旋回角」で設定し、「適用」「保存」を押す。
正面を0°とする角度の大きさを0〜180°で指定する。例えば83.5°なら青は+83.5°、赤は-83.5°。
設定ファイルではトップレベルの`homing_theta_deg`を使用し、省略時は従来どおり90°。
準備画面のコート選択・手順表示とデバッグ画面には、適用済みの旋回角を表示する。
z上昇量は「2 調整 → アーム → z」の「ホーミング上昇量」で設定する。
`homing_retreat_mm`を使用し、省略時は50mm。0より大きい値が必要で、可動域内に収まることを確認する。
r後退量は「2 調整 → アーム → r」の「ホーミング戻し量」で設定する。
同じ`homing_retreat_mm`を使用し、省略時100mm。実際の戻し量は機体設定に従う。
0より大きく、原点から後退した位置が可動域内に収まる値を指定する。

r・zの探索とθ旋回の最高速度は、各軸の最高速度に`homing_speed_percent`を掛けた値（省略時20%）。
z上昇・r後退・スタート後の正面復帰は、各軸の最高速度を使う。
これらの移動は位置指令を徐々に更新して、移動開始時に加速し、終点へ近づくと減速する。
加速度は各軸の最高速度÷`jog_ramp_seconds`（GUIの「加減速時間」）で、手動操作と共通。
加減速時間を0にした場合は等速で移動する。
各移動段階の制限時間はGUIの要求値を使用し、パッドは180秒。
リミットが既に作動している場合はその位置で停止を確認する。
NO接点は断線でも未押下と同じ値になるため、配線と接点表示を確認する。

緊停・停止・通信断・モータ異常・時間超過で中断する。
ホーミング中は設定変更・通常操縦・個別テスト・コート変更を受け付けない。
設定した順序と停止条件はソフトウェアテストで確認する。
実機の正方向・干渉・リミット位置・停止距離は実機で確認する。

θ=0°は真正面である。以前の「ボーナスの反対側を0°」として登録した位置・旋回較正値は、
新しい座標基準に合わせて再確認する。

通常操縦の加減速は軸設定の jog_ramp_seconds（「加減速時間」）で指定する。
r・θの初期設定は0.4秒。停止から最高速度までの時間で、反転時は減速してから逆向きに加速する。
中立入力でもこの時間に応じて減速するため、スティックを離してから停止するまで短い移動が生じる。
0秒では速度を即時変更する。zは既定0秒。
原点採用済みの通常操縦では、可動域端とリミットスイッチの原点座標に向けて先行減速する。
接点作動・緊停・通信異常・明示的な停止操作は加減速待ちをせず停止する。
原点位置がまだ分からないホーミング探索では、接点での停止衝撃を「ホーミング速度率」で調整する。

準備画面のコントローラガイドでは、Createを1秒長押しした後に離して開始する。
デバッグ画面では従来どおりCreateの1秒保持で開始する。
