# r・z自動ホーミング

「2 調整 → 軸・原点」の「r・z自動ホーミング」を使用する。
人間が、EEがシューティングボックスの反対側を向き、z下降とr前進の全経路で干渉しないことを確認して開始する。
DualSenseでも開始できる。通常操作・個別テストを停止し、スティック・トリガー・十字キーを中立にする。
姿勢と全経路を確認してから、Createを1秒保持する。
この長押しがGUIの姿勢確認に相当する。画面上部に確認時間を表示し、離すと取り消す。
パッド操作の制限時間は各軸180秒。変更する場合はGUIから開始する。
PSで中断でき、ホーミング中のパッド切断も中断する。完了・中断後、再度開始するには両ボタンを離す。
Optionsは通常の運転再開に使用する。

θの自動旋回・原点採用は行わない。θの原点は従来の手動採用で設定する。

1. 全出力を停止する。
2. zだけを有効化し、下端リミットまで低速で下降する。
3. 停止し、zに設定の原点座標を採用する。
4. 停止応答後、rだけを有効化して前端リミットまで低速で前進する。
5. 停止し、rに設定の原点座標を採用する。完了後も自動で運転再開しない。

方向は機体プロファイルのリミット方向と換算係数から求める。
既定設定ではz下端=0mm、r前端=120mm。rの値は `origin_position` で変更できる。
探索速度は通常軸速度の20%、上限はz=5mm/s・r=10mm/s。
機体座標のソフトリミットによらず探索するが、FWの絶対可動域制限は維持する。

各軸の制限時間はGUIで10〜1800秒に設定可能（初期180秒）。
開始時に接点が既に到達状態ならその軸は移動せず原点を採用する。
NC接点の断線と実際の到達はソフトウェアだけでは区別できないため、配線と接点表示を事前確認する。
この手順は押し当て後の後退・再接近を行わない。

Space、`s`、中断ボタン、通信断、モータ異常、時間超過で中断する。
ホーミング中は通常操作・設定変更・個別テストを受け付けない。
通信と状態遷移はソフトウェアテストで検証し、接点位置・停止距離・干渉は実機で確認する。
