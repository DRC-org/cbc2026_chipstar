# 出力停止とzの位置保持

通常の「出力停止・z保持」は、r・θと周辺機構の出力を停止し、zの現在位置を保持する。
設定適用中もzの保持を継続し、完了後に自動で運転へ戻らない。
状態欄の「出力停止・z保持」は、zのモータが通電していることを表す。

「停止・保持」はr・θ・zを保持する。「全トルク解除」、ソフト緊停、通信断では
zの保持も解除される。全トルク解除を使う際は、自重で下がる機構を支える必要がある。

設定照合の失敗ではz保持を継続する。モータCAN IDやzのslotを変更する場合は、
全トルク解除後に設定を適用する。保持中は制御を止めるFlash保存を延期する。
hostの設定ファイルへの保存は通常どおり行える。

## 通信仕様

CCTLの`HOLD <mask>`は、指定slotを現在位置で保持してSAFEへ移行する。
maskは1〜7。保持中のTARGET、JOG、HOME、再初期化、保存設定の初期化は受け付けない。
同じmaskの再要求は保持位置を更新しない。`RUN`で通常運転へ戻り、
`STOP`または`SAFE`で全トルクを解除する。通信監視とフィードバック監視は保持中も働く。

STATEの`hold=<mask>`が実際の保持対象を示す。hostはこのフィールドのない旧FWで
z保持を開始しない。zに対応するslotの選択はhostが機体設定から行う。
