# rθz 機体構成

キャチロボ2026 の把持ハンドを位置決めする **rθz 3軸機構**の構成と、各軸の駆動系・
座標定義をまとめる。機体座標とモータの換算は`host/config/rtheta.toml`、デバイスの
リアルタイム制御は`cctl`に実装する（[host_machine_profile.md](host_machine_profile.md)、
[motor_protocols.md](motor_protocols.md)参照）。

## 座標系

円盤ベースを基準とした円筒座標。

| 軸 | 記号 | 意味 | 駆動モータ | 伝達機構 |
|---|---|---|---|---|
| θ | 回転 | ベース回りの旋回角 | M3508 + C620 | 内歯車（ターンテーブル）+ ピニオン |
| r | 半径 | 旋回中心からの水平距離 | RobStride EL05 | ラック&ピニオン |
| z | 高さ | 鉛直方向の昇降 | Damiao DM-S3519 | タイミングベルト |

```
        z ↑（垂直タワーをベルトで昇降）
          |
          |      r →（水平ビーム＝ラックを前後送り）
          |    /
          |  /
   ┌──────●──────┐   θ（円盤ベースを内歯車で旋回）
   └─────────────┘
```

## 機構の要点

### θ軸（内歯車 + ピニオン）
- 円盤ベース外周が**内歯リングギア（ターンテーブル）**になっており、M3508 に付いた
  **ピニオン**で駆動して機体全体を旋回させる。
- 減速比 = `(内歯車歯数 / ピニオン歯数) × C620内蔵減速比(3591/187 ≈ 19.2032)`。
- **歯数は要実測**。確定後、`host/config/rtheta.toml`のθ軸`native_per_unit`へ反映する。
- M3508/C620 は絶対位置を持たないため、cctl 側で**多回転角の積算**と**位置→速度カスケードPID**で
  位置制御する。基板側の原点は起動時姿勢で、機体としての原点は host が採る。

### r軸（ラック&ピニオン）
- 水平ビーム上面が**ラック**、EL05 出力軸の**ピニオン**で前後送りする。
- EL05 は**減速比 9:1 内蔵**、出力軸で位置制御（Position モード）できる。
- 送り量 = `ピニオン有効円周 × 出力回転数`。**ピニオン諸元は要実測**
  （`R_MM_PER_OUTPUT_REV` 暫定）。
- EL05 の位置範囲は約 ±4π ≈ ±12.57 rad（出力軸）。ラック全長がこの範囲に収まること。

### z軸（タイミングベルト）
- 垂直タワーに沿ってキャリッジを**タイミングベルト**で昇降。
- DM-S3519 の **Position-Velocity モード**（目標位置＋速度上限）でネイティブ位置制御。
- 送り量 = `プーリ有効円周 × モータ出力回転数`。**プーリ諸元は要実測**
  （`Z_MM_PER_OUTPUT_REV` 暫定）。
- **重力負荷**があるため、速度0の開ループ保持ではなく位置モードで保持する。
- DM は**電源投入時に位置 = 0.0 rad**。機体としての z 原点は下端の SW2 で採る。

## 原点出し（ホーミング）

半手動で行う。オペレータがコントローラで軸を動かし、hostが原点を採る。自動で軸を
探索させないので、機構がどこかへ当たる前に手を止められる。

| 軸 | 接点 | 採用の仕方 | 採用する値 |
|---|---|---|---|
| r | SW1 | 前進しきってビーム後端がスイッチを叩く | `maximum`（暫定120mm） |
| z | SW2 | 下端まで降ろす | `minimum`（0mm） |
| θ | なし | 姿勢を合わせてGUIの「現在位置を原点に」 | 0deg |

スイッチはOMRON SS-10GL13。cctlのJ5/J6へ**B接点（常閉）**で入れる。COMをpin 1（GND）、
NCをpin 2（信号）へ繋ぐ。断線が「到達」側に倒れ、機構へ突っ込まない。

θにスイッチを置かないのは、赤青コートで取り付けを共用できないためである。試合ごとに
セッティングで姿勢を合わせ、その場で原点を採る。可動域はケーブルの巻き込み制限を
原点対称に取る。

原点を採るまでは可動域のクランプが効かない。低速で当てること。r と z は到達している
間だけスイッチへ近づく向きの入力を捨てるので、逆向きに戻せば抜けられる。

大会規定の非常停止は動力電源を直接切る配線で成立させる。接点入力はこれを代替しない。

## 要実測パラメータ一覧

以下は実機確定後に`host/config/rtheta.toml`を更新する。

- z: プーリ歯数×ベルトピッチまたは有効径×πから`native_per_unit`、`minimum/maximum`
- r: ピニオンのモジュール×歯数から`native_per_unit`、`minimum/maximum`
- θ: リング歯数、ピニオン歯数、C620減速比から`native_per_unit`、`minimum/maximum`
- 各軸の正方向を`input_sign`へ反映

DMのフィードバック復号レンジ、モータ電流上限、制御ゲインなど基板が守る絶対条件は
`cctl/src/device_config.hpp`に置く。通常の機体変更では触らない。
