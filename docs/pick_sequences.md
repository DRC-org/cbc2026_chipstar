# 取得シーケンス

「1 操縦 → 取得シーケンス」で取得グループと受渡し先を選び、各操作を実行する。
受渡し先の左右は、フィールドに向かって見た向きで表す。

| 操作 | 標準の動作 |
|---|---|
| 取得準備 | ワークなし移動高さで対象ワーク上空へr・θ・z移動 → EE展開 → 取得向きへEE回転 → 取得レベルまで把持開 → 取得高さへ下降 |
| 取得 | 手動で合わせたr・θを保って把持レベルまで把持閉 → ワークあり移動高さへ垂直上昇 |
| 受け渡し | 手動で合わせた受け渡し位置でEEたたみ → 揺れ待ち → 外枠内まで段階下降 → 受け渡しレベルまで把持開 → ワークあり移動高さへ垂直退避 |

３操作はそれぞれ単独実行できる。「３操作を連続実行」は順番に連結する。
単独実行では、取得準備と取得の間に取得位置のr・θを、取得と受け渡しの間に受け渡し位置のr・θを手動調整する。
連続実行では手動調整を挟まず、登録した取得位置と受け渡し上空位置を使う。
現在位置から開始し、固定の待機姿勢への復帰は要求しない。
GUIから開始すると実行中は画面操作として扱い、必要なら通常運転も開始する。
完了後は開始前の画面操作・パッド操作へ戻り、手動操作を続けられる。
原点・通信・機体設定・対象サーボの出力許可は既存の機体操作と同じ条件を使う。
アームだけの工程を作れば、EEを動かさず位置移動から試せる。

実行中はグループ・受渡し先・設定値を開始時の値に固定する。
選択を変えても現在の動作は変わらず、次回の開始で使われる。
完了時は位置と把持指令を保持し、画面の手動操作や次のシーケンスを実行できる。
把持の成否は操作者が確認する。

## 位置・姿勢の登録

「位置・姿勢・工程を設定」を開く。

- 取得グループ：名前、r・θ、取得高さ、取得向きのEE回転指令。
- 移動高さ・受渡し位置：ワークなし／ありの移動高さ、外枠へ下げる1段の量、左右それぞれのr・θ・外枠内z・EE回転指令。
- EE姿勢：展開・たたみ、３本それぞれの取得時開・把持閉・受け渡し時開指令。標準値は把持閉700 µs、受け渡し時開500 µs。
- 速度・到達・待ち時間：アーム速度率、到達許容差、工程制限時間。

アームを手動で位置合わせし、「現在のr・θを登録」「現在zを登録」で編集欄に取り込む。
EEは通常操作で姿勢を合わせ、「現在指令を登録」で取り込む。PWMサーボの値は実測位置ではなく指令値。
直接数値を入力することもできる。グループは複製・追加・削除できる。

登録・編集しただけでは動作設定は変わらない。「適用」で次回以降の実行に反映し、
「保存」でファイルに保存する。初期設定は機体設定の開始値から作るため、実際の位置と姿勢を登録する。
EEの開・閉や展開・たたみも、それぞれの実機指令値に合わせる。
通常操縦でも同じ値を使い、DualSenseの←で取得時開、→で把持閉、○で受け渡し時開を3本へ一括指令する。

保存先は機体プロファイルと同じディレクトリの `<名前>.sequences.toml`。
例えば `rtheta.toml` なら `rtheta.sequences.toml`。
機体プロファイルの設定適用・保存とは独立している。
ファイルを直接編集した場合は「ファイル再読込」で適用する。
読込みエラーは操作欄に表示し、不正ファイルは上書きせずに機体設定由来の初期値で開く。

## 工程の変更

「工程の順序・同時動作」で対象操作を選び、↑・↓で工程を並べ替える。
工程は追加・削除でき、動作をすべて外すと時間待ちだけの工程になる。
同じ工程に追加した動作は同時に開始する。各工程の「開始後の待ち」は、全動作の開始から数える。
同一工程で同じ軸に異なる動作を割り当てた場合は、適用時に該当工程と軸を表示する。

ワーク上空への移動はグループのr・θとワークなし移動高さへの３軸移動。
単独の受け渡しは開始時のr・θを保つため、取得完了後にワークあり移動高さのまま手動で位置を合わせる。
「３操作を連続実行」では、ワークあり移動高さを保って選択側の登録r・θへ自動移動する。
外枠内への下降は、ワークあり移動高さから登録した外枠内zまで、設定した1段量以下に分割して進む。
外枠に入ったかを検出するセンサはないため、外枠内zは実機で位置を合わせて登録する。
EEたたみ工程の標準待ち時間は2秒で、実際の揺れに合わせて工程の待ち時間を編集する。

アームの同時移動は、各軸の設定速度に速度率を掛け、共通の所要時間で加減速する。
各軸の設定速度を超えないよう目標位置を補間し、最終目標へ実測が許容差内に到達するまで待つ。
EEの動作完了は工程の待ち時間で調整する。アームとEEを同じ工程に置いた場合は、
アーム到達と待ち時間の両方が成立してから次へ進む。
経路は登録した動作順に従う。フィールド形状から経路を生成・回避する機能はない。

## 中断と調整

上部の停止ボタンまたは `s` で残り工程を取り消す。緊停はSpace。
停止時は既存の停止動作に従い、アームを保持しEE出力を解除する。工程完了時の保持とは異なる。
通信異常やEE異常でも残り工程を取り消し、復旧後に自動再開しない。
調整後は実行したい操作を選んで開始する。

機体の「模擬接続」でも登録・保存・各操作・連続実行を確認できる。
模擬接続は通信と操作順の検証用で、機構の干渉や把持の成否は再現しない。
