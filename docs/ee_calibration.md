# EE回転のGUI較正

「2 調整 → EE → EE全体回転」の「フィールド方向の2点較正」を使います。
先に接続先IDを適用し、θの原点を既知のフィールド角に合わせて採用してください。

1. 通常運転・個別テスト・STS駆動を停止します。
2. 「較正開始・EE回転を脱力」を押します。対象STSだけを無効化し、トルクOFFを読み戻します。r・θ・zの出力状態は変更しません。
3. 手でEEをフィールド0°に合わせ、「この向きを0°として取込」を押します。
4. 手で90°または180°に合わせ、対応する取込ボタンを押します。2点目を取り直すと直前の2点目を置き換えます。
5. 「較正終了（脱力を維持）」→「計算結果を編集値へ反映」→通常の「適用」「保存」で確定します。

取込では毎回トルクOFFを確認してから位置レジスタを読み出し、その応答時点のθ実測値と組み合わせます。読取り中は両軸を静止させてください。古い監視履歴から較正値を採用しません。
較正中は通常運転や他のSTS操作へ切り替えられません。停止・緊停・画面変更は取込を中断します。較正終了でトルクを再投入しません。

## 角度と減速機構

較正値は `zero0_count`（取付オフセット）と `counts_per_deg`（符号・減速比を含む回転換算係数）です。初期値は実機で較正した値ではありません。
2点間のθの差も計算に含めますが、θの原点基準を変えた場合や、サーボ交換・ホーンの組み直し・サーボ内部の位置補正変更後は再較正してください。

EE回転用STSはモード0のまま、最小角度・最大角度をともに0にして多回転絶対位置を使用します。
16T:48Tの3:1減速ではEEの180°がサーボ6144 countに相当します。通常操作は符号付き±28672 countを扱います。
電源断後は回転数が失われるため、再起動時は既知のEE姿勢で0°点を取り込み直します。
通常操作の0°・180°切替が全θ姿勢で成立することを、較正の成功だけでは保証しません。機構の対称性や多回転操作の可否は別途確認が必要です。

## API

GUIと共通の `sts` アクションで、次のTOML要求を送れます。CLI/APIでは通常の操作権取得が必要です。

```toml
operation = "teach"
id = 1
```

```toml
operation = "capture"
field_deg = 0 # 0 / 90 / 180
```

```toml
operation = "end_teach"
```

`status.sts`の`teach_id`が較正中のID、`teach_zero`・`teach_half`が取得済みの2点です。各点に`field_deg`・`count`・`theta_deg`を持ちます。結果は`teach_result_id`に対応するサーボだけへ反映します。

ソフトウェア試験では取込・排他・中断・z保持状態の継続を模擬接続で検証しています。実機の方位合わせと較正値は人間が確認してください。

## 速度と加速度

`speed_position_per_second = 0`は位置指令の速度制限を設けない特殊値です。製品仕様の無負荷速度は45rpmで、実際の速度は負荷で低下します。ST-3215-C018の実機では、加速度レジスタは0〜50をそのまま保持し、51〜254は50へ丸められました。この機体の通常設定は速度0・加速度50を使用します。
