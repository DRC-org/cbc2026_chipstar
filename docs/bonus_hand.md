# ボーナスハンド操作

ボーナスハンドは、ボックス選択用のDCモータとAMT102-V、蓋開閉用STS3215、整列用STS3215をhostでまとめて扱う。基板FWは汎用のDuty・エンコーダ・STS位置制御のままとし、受け渡し位置、各ボックス位置、動作順は機体プロファイルに置く。

## セッティング

「調整 → ボーナス」でDCの移動出力・減速、駆動方向、ボックス位置、蓋・整列サーボの端点を編集する。
通常操作を無効にしたまま、単体テストと位置の登録を進められる。

1. 「DCモータを単体テスト」で正負の出力を確認する。表示と入力は%単位で、押している間だけ動く。
2. 受け渡し位置へ合わせ、出力を解除して調整画面へ戻り、「現在位置を受け渡し基準に登録」を押す。
3. 各ボックスへ合わせ、同様に「現在位置を取込」で相対カウントを編集値へ取り込む。
4. 蓋・整列の各端点は現在位置を取り込むか数値入力し、「単体テストへ」で確認する。
5. 「適用」「保存」で確定し、準備ができたらボーナスと各STSの通常操作を有効にする。

DCの「移動出力」は単体テストの範囲と基板のDuty上限にも自動反映する。
基板側に別の低い`max_duty`を指定しても、ボーナスの移動出力を妨げない。
ボーナス選択軸では旧`dc_motors.maximum_duty`は移動出力に使用しない。
単体テストは基板へ直接Dutyを送る。正出力でエンコーダが減る場合は「カウント増加側の駆動方向」を「逆転」に設定する。
通常操作と自動移動はこの駆動方向を使い、正方向をカウント増加側へ揃える。
DC基板のランプ幅・更新間隔・反転待ち・通信期限・PWM周波数も、この画面または「調整 → 基板」で編集できる。

操縦・調整・DC単体テストの「エンコーダ実測」は、DCMDが送った累積カウントと受信件数、最終受信からの時間、X相通過回数を表示する。
受信件数が増えているのにcountが変わらない場合は、基板から同じカウントが届いている。応答が300 ms以上途切れた場合は「現在位置は不明」と表示し、残った数字を最終受信値として区別する。
接続先はENC1のJ6。J5・J6はどちらもENC0と印刷されているが、現在のFWはJ6を読む（[配線ガイド](wiring.md)）。

受け渡し位置側のリミットスイッチは任意で、未装着でも使用できる。未装着時は制御電源を入れ直すたびに次の順で登録する。

1. 手動モードで選択軸を動かし、EEから受け取る一定位置へ合わせる。
2. 「現在位置を受け渡し位置に登録」を押す。DualSenseではR1を押しながらCreateを押す。
3. 表示が「受け渡し位置から +0 count」になったことを確認する。
4. 各ボックス位置は、この位置からの相対距離としてmmで入力するか、実位置で「現在位置を取込」を押す。

通信断、接続先変更、基板再起動を検出すると登録は破棄される。再接続後はもう一度受け渡し位置を登録する。

リミットスイッチを使う場合は`[bonus.handoff_limit]`にDCMDの接点と、受け渡し位置へ動くエンコーダ方向の符号を設定する。手動操作では接点へ近づく方向だけ停止し、反対方向へは退避できる。半自動の復帰はAMT102-Vの登録位置へ近づいた後も低速でスイッチを探し、到達時のカウントを新しい受け渡し位置として採用する。

## 手動モード

画面から選択軸の正逆転と停止、整列軸の往復、蓋の開閉を個別に操作できる。選択軸の方向ボタンは押している間だけDutyを更新し、画面入力が200 ms途切れるとhostがDuty 0を送る。

DualSenseではR1を押している間をボーナス操作層とする。←/→が選択軸、↑/↓が整列/復帰、○/□が蓋開/閉、L3/R3がボックス選択である。

## 半自動モード

シュート先を選び、「3個受け取り」を受け渡しごとに押す。6個に達すると次を実行する。

1. AMT102-Vを見ながら選択ボックスへ移動する。
2. 整列STSを整列位置まで動かし、元の位置へ戻す。
3. 蓋を開け、設定時間後に閉じる。
4. 選択軸を受け渡し位置へ戻し、本数を0へ戻す。

「選択ボックスへシュート」は本数に関係なく同じ一連動作を開始する。DualSenseではR1+×が3個受取、R1+△が明示シュート、R1+Optionsが手動/半自動切替である。PSはどの工程からでも機体と周辺基板を停止する。

## 設定

`host/config/rtheta.toml`の`[bonus]`と`[[bonus.boxes]]`を使用する。初期値は実機値ではないため`enabled=false`としてある。調整画面と単体テストで方向、STS端点、各ボックスの相対カウントを測り、値を反映してから`bonus.enabled=true`と2台のSTSの`enabled=true`を設定する。

選択軸は目標から遠いと`selector_duty`、近づくと`selector_slow_duty`で動き、`selector_tolerance_counts`以内で停止する。自動動作が`cycle_timeout_ms`以内に完了しない場合は全出力を停止する。

AMT102-VのDIP分解能はPPRで設定する。DCMDはA/B相の4逓倍カウントを読むため、1回転のカウント数は`encoder_ppr * 4`になる。AMT102-Vの工場設定は2048 PPRで、M1・20歯のピニオンは1回転で`π × 1 × 20 = 62.832 mm`進む。この構成では8192 count/回転、約130.38 count/mmである。DIPを変更している場合は、調整画面のPPRを実機のスイッチ設定に合わせる。

```toml
[bonus.handoff_limit]
input = 0             # DCMD SW1=0、SW2=1、SW3=2
direction = -1        # 受け渡し位置へ近づくDutyの符号
normally_closed = true
```
