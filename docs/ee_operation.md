# EEの割当・単体テスト・通常操作

「2 調整 → EE」で全体回転・畳み・把持1〜3を設定する。
伸縮軸は運用対象に含めず、EE先端のリミットスイッチも使用しない。

## 割当と校正

全体回転はSTS3215、畳み・把持はPWMサーボの既存プロファイルを利用する。
割当追加時は出力無効。候補ID/チャネル・範囲・開始指令は校正値ではない。
配線と動作範囲を確認して編集し、上部の「適用」で反映する。
サーボの役割名は `ee_rotation`、`ee_fold`、`ee_grip_1`〜`ee_grip_3`。

STSのEE回転速度は`speed_position_per_second`だけで指定する。hostの目標更新と
STS位置指令の速度には同じ値を使い、別の内部速度上限は持たない。範囲は
1〜1000 count/sで、1000が通信プロトコル上の最大値。

- 全体回転：STS側16T・EE側48Tのベルトで3:1減速。指令はサーボ軸の0〜4095カウントで、通常位置モード0のみ。
  EEの角度差は `カウント差 × 360 / 4096 / 3` 度。1024カウントでEEが30°、3072カウントで90°回転する。
  1カウントはEEで約0.0293°、単回転の指令範囲はEEで約120°に相当する。EEの基準方向は別途位置合わせする。
  通常操作はフィールド基準0°/180°を指定し、θ実測で姿勢を補正する。
  取付オフセットと符号付き換算係数は[GUIの2点較正](ee_calibration.md)で設定する。
  3:1減速では同じθで0°と180°の両方へ移動することは単回転範囲に収まらない。
  較正では0°・90°を選べる。通常操作の姿勢・可動範囲は実機で別途確認する。
- 畳み：`minimum_us`と`maximum_us`を展開・畳みの2位置として使う。`input_sign`で十字キー上下との対応を反転できる。
- 把持：個体ごとの`minimum_us`と`maximum_us`を開・閉の2位置として使う。`input_sign`で十字キー左右との対応を反転できる。
  PWMサーボは`speed_us_per_second`と`acceleration_us_per_second2`で加速・定速・減速しながら端点へ移動する。

「単体テスト」または「3 診断 → 個別テスト」のEE名を選ぶと、通常操縦を停止して対象を選択する。
選択だけでは駆動せず、「指定位置へ移動・保持」で開始する。EEとして登録した対象には設定範囲を適用する。
タブを離れるとテストを終了する。通常出力の許可前でも単体テストで校正できる。

## 通常操作

校正後に「通常出力を許可」を設定・適用・保存する。通常の運転再開後、
「1 操縦 → EE」で各軸の値を明示的に送る。RUNだけではEEを有効化しない。
PWMは指定値をSETした後にENABLEする。STSはFWの現在位置での初期化処理を通す。
PWMには現在位置の検出がないため、最初の指定位置まで移動することを前提に操作する。

把持3本への一括ボタンは、各軸の編集値を検証して順に送信する。3個の閉位置が異なっても扱える。
同一瞬間の開始や把持成功の確認は保証しない。

標準パッド割当は、△＝全体回転の0°/180°切替、十字キー上下＝畳み、十字キー左右＝把持3本。
全体回転は切替後もθ実測に合わせて補正する。畳み・把持は一度押すと設定された端点まで移動する。
上・右は通常`maximum_us`、下・左は`minimum_us`へ移動し、各軸の「端点を反転」で対応を逆にできる。
L1では機体プロファイルの`slow_speed_percent`を速度に掛ける。
把持3本はすべての割当・通常出力許可が必要。各個体の範囲・方向・速度を適用する。

RUN後にEE入力を一度中立に戻し、最初に操作した軸へ設定の「開始指令」を送る。
開始位置への移動があるため、開始指令も機構に合わせて校正する。RUNだけでは出力しない。
停止後の再操作でも開始指令を使う。
「標準パッド割当」を別の入力軸に変更すると、その軸では変更した割当を優先する。
L2/R2は0〜1の片方向入力。アームと同じ入力を選ぶと両方が動く。
画面操作・AI操作中には標準パッド割当は働かない。

停止・緊停・通信異常ではEE出力を解除し、操作中の目標を破棄する。再開だけで自動復帰しない。
通常操縦は個別テスト・STS管理の駆動・ホーミングと排他。

GUIと同じAPIは `ee` アクションへ以下のTOMLを渡す。CLIは通常の操作権取得後に使用する。

```toml
[targets]
ee_grip_1 = 1500
ee_grip_2 = 1500
ee_grip_3 = 1500
```

数値は形式例であり開閉の校正値ではない。設定・開始手順は模擬接続でも確認できるが、
パルス幅と機械姿勢の関係、電源・配線・干渉は実機確認が必要。
