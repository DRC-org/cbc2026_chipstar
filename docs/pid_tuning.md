# PIDゲインの調整

GUIで **2 → PID調整** を開く。Pは誤差への反応、Iは残る誤差の補償、Dは誤差変化への反応を調整する。

各軸の設定は機体プロファイルのslot割当から選ばれる。

| slot | 対象 | 調整項目 |
|---|---|---|
| 0 | EL05（r） | 内部位置Kp、速度・電流上限 |
| 1 | M3508（θ） | CCTLの位置PID・速度PID、速度・電流上限 |
| 2 | M3508（z） | slot 1と独立した位置PID・速度PID、速度・電流上限 |

EL05の位置Ki/Kdと速度ゲインは現在の設定APIでは公開していない。
M3508の速度上限は減速前モータ軸のrpm。機体のmm/s・deg/sは「軸・原点」で設定する。

1. 各項目の説明と適用値を確認して編集する。数値はドラッグまたは直接入力できる。
2. 「戻す」でその項目だけをhostの適用値へ戻せる。「編集を戻す」は全編集を破棄する。
3. 運転・個別テストの出力を停止して、上部の「適用」または`:apply`を実行する。
4. 基板との設定照合が完了したことを確認し、通常の低速操作や個別テストで挙動を確認する。
5. 採用する設定を「保存」または`:w`でファイルへ保存する。

適用はPID画面だけでなく、軸設定・基板パラメータなどの未適用編集も含む。
「適用値」はhostの適用中設定であり、各項目単独の実機読戻し表示ではない。
基板への反映状況は画面上部の設定照合状態で確認する。

各項目を変更したときの振動、追従、発熱を確認する。出力上限に達している場合、
ゲインだけを増やしても追従が改善しない場合がある。現在位置表示は状態確認用で、
制御周期ごとの波形や速度・電流の応答グラフではない。

Spaceはソフト緊停。解除後に自動でRUNへ戻らない。Escは数値編集を終了する操作。
