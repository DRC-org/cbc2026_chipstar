# PIDゲインの調整

GUIで **2 調整 → アーム** を開き、調整する軸を選ぶ。Pは誤差への反応、Iは残る誤差の補償、Dは誤差変化への反応を調整する。

各軸の設定は機体プロファイルのslot割当から選ばれる。

| slot | 対象 | 調整項目 |
|---|---|---|
| 0 | EL05（r） | 内部位置Kp、電流上限 |
| 1 | M3508（θ） | CCTLの位置PID・速度PID、電流上限 |
| 2 | M3508（z） | slot 1と独立した位置PID・速度PID、電流上限 |

EL05の位置Ki/Kdと速度ゲインは現在の設定APIでは公開していない。
速度は同じアーム画面の「最高速度」で設定する。hostが換算係数を使ってEL05のrad/sまたはM3508のrpmへ変換し、CCTLへ適用する。

1. 各項目の説明と適用値を確認して編集する。数値はドラッグまたは直接入力できる。
2. 「戻す」でその項目だけをhostの適用値へ戻せる。「編集を戻す」は全編集を破棄する。
3. 運転・個別テストの出力を停止して、上部の「適用」または`:apply`を実行する。
4. 基板との設定照合が完了したことを確認し、通常の低速操作や個別テストで挙動を確認する。
5. 採用する設定を「保存」または`:w`でファイルへ保存する。

適用はPID画面だけでなく、軸設定・基板パラメータなどの未適用編集も含む。
「適用値」はhostの適用中設定であり、各項目単独の実機読戻し表示ではない。
基板への反映状況は画面上部の設定照合状態で確認する。

各項目を変更したときの振動、追従、発熱を確認する。出力上限に達している場合、
ゲインだけを増やしても追従が改善しない場合がある。位置応答グラフを併用し、速度・電流の内部応答とは区別する。

Spaceはソフト緊停。解除後に自動でRUNへ戻らない。Escは数値編集を終了する操作。

## 応答グラフ

同じ画面の上部で、軸を選び、目標位置・実測位置と追従誤差を確認する。
受信時に全軸の直近120秒・最大6000サンプルを記録するので、個別テストを終了して
PID画面へ戻っても応答を確認できる。表示幅は5〜120秒。「表示を停止」は表示だけを固定し、
モータを停止しない。停止操作にはSpaceまたは`s`を使う。

横軸はCCTL時刻の差分、縦軸は受信時の原点・換算係数によるmm/deg。
RMS（二乗平均平方根）と最大絶対誤差は、表示区間の出力中・原点確認済みの有効サンプルだけで集計する。
無効応答、250msを超える欠測、原点・換算・有効状態の変化では線を切る。
CSVは表示軸だけでなく保持している全軸を保存し、基板時刻・受信時刻と有効フラグも含む。

CCTLの位置配信を利用するためFW更新は不要。既定の配信周期は50ms。
速度ループ内部の目標rpm・実測rpm・電流や、制御周期ごとの高速振動はこのグラフでは観測できない。
